# 🫧 Bubble Mate — 프로페셔널 디테일링 용품 쇼핑몰

자동차 디테일링 용품 쇼핑몰의 **메인 페이지**와 **상품 상세페이지**를 구현한 프로젝트입니다.
바닐라 HTML / CSS / JavaScript로만 만들어졌으며 별도의 빌드 과정 없이 바로 실행됩니다.

색상 컨셉은 **민트 배경 + 파란 포인트** 입니다.

---

## 🚀 실행 방법

빌드 도구나 서버가 필요 없습니다. 폴더를 받은 뒤 `index.html`을 더블클릭(또는 브라우저로 열기)하면 끝입니다.

```
bubblemate/
└── index.html  ← 이 파일을 브라우저로 열기
```

> 참고: 폰트는 Google Fonts CDN에서 불러오므로, 인터넷이 연결된 환경에서 열면 디자인 폰트까지 정상 적용됩니다.

---

## 📁 파일 구조

총 5개 파일로 구성되어 있습니다. 역할에 따라 명확히 분리해 두었습니다.

| 파일 | 역할 | 설명 |
|------|------|------|
| `index.html` | **구조 (뼈대)** | `header` / `nav` / `section` / `footer` 시맨틱 태그로 작성. 메인·상세 두 화면이 한 파일 안에 들어 있음 |
| `style.css` | **디자인** | 색상·레이아웃·애니메이션. 색상은 모두 CSS 변수(`:root`)로 관리 |
| `app.js` | **동작** | 화면 전환, 캐러셀, 상품 렌더링, 옵션창, 결제 등 모든 인터랙션 |
| `products.js` | **데이터** | 상품 8개 정보, 카테고리, 배너, 리뷰 데이터. **사진 교체도 여기서 함** |
| `README.md` | **문서** | 이 파일 |

## 🖥️ 화면 구성 (페이지 2개)

한 개의 HTML 파일 안에 두 화면을 넣고, JavaScript로 전환하는 **SPA(단일 페이지) 방식**입니다.
(`#homeView` 와 `#detailView` 중 하나만 보이도록 `hidden` 속성으로 토글)

### 1. 메인 페이지 (`#homeView`)

- **헤더** — 로고, 검색창, 메뉴(전체상품·세트·외부·내부·전문가도구), 장바구니·계정 아이콘
- **히어로 배너** — 좌우 화살표(`<` `>`)로 **배너 박스 안의 이미지+텍스트만** 슬라이드 전환되는 캐러셀 (5.5초 자동 전환 + 하단 점 네비게이션)
- **카테고리** — 아이콘 9개 (카샴푸·폼건/분무기·세차타월·광택/코팅·휠/타이어·워시미트·유리세정·실내관리·전체보기)
- **실시간 인기 랭킹 상품** — 상품 카드 8개 그리드 (찜 하트, 브랜드, 이름, 파란 할인율+가격, 노란별 평점)
- **프로모션 배너** — 2칸 (연보라 / 연녹색)
- **리뷰** — 포토리뷰 3개 + 파란 별점
- **푸터** — 다크 네이비, 회사 정보·링크

### 2. 상세페이지 (`#detailView`)

- **좌측 갤러리** — 큰 메인 이미지 + 썸네일 3개 (클릭 시 메인 교체)
- **우측 구매 패널** — 브랜드, 상품명, 노란별 평점, 빨강 할인율+큰 가격+취소선 원가, "버블메이트 전문가 팁" 박스, 수량 조절, 문의하기/구매하기 버튼, 무료배송·품질보증
- **주요 특징** — 카드 2개
- **사용 방법** — 01·02·03 번호 타임라인
- **푸터** — 뉴스레터 구독 포함

## 🔄 동작 흐름

### 화면 전환 (홈 ↔ 상세)

```
[메인] 인기상품 카드 클릭
        │
        ▼
   openDetail(상품id) 호출
        │  · 해당 상품 데이터로 상세페이지를 통째로 다시 그림 (renderDetail)
        │  · 홈 숨기고 상세 표시
        │  · 맨 위로 스크롤
        │  · 주소에 #product=상품id 기록 (브라우저 뒤로가기 지원)
        ▼
     [상세페이지]
        │
        ├─ 로고 클릭         → goHome() → 메인 복귀
        └─ 브라우저 뒤로가기  → popstate → 메인 복귀
```

> **핵심:** 어떤 상품을 누르든, 그 상품에 맞게 **이름·가격·할인율·평점·전문가팁·주요특징·사용법까지 모든 텍스트가 완전히 바뀝니다.** (`products.js`의 데이터 기준)

### 구매 흐름

```
[구매하기] 버튼 클릭
   → 화면 아래에서 옵션창이 슬라이드업
     · 용량 선택 (500ml / 1L / 2L 대용량)
     · 수량 조절
     · 총 결제금액 자동 계산
   → [toss pay 원클릭 결제] 버튼
     → 결제 진행 토스트 메시지 표시
```

## 🖼️ 사진 넣는 방법 (중요)

현재 모든 이미지 자리는 **"여기에 ○○ 사진 넣으세요"** 안내 박스로 표시되어 있습니다.
실제 사진은 **`products.js` 한 파일에서** 관리하므로, 거기서 안내문을 실제 이미지로 바꾸면 됩니다.

### 교체할 위치

| 데이터 | 위치 | 설명 |
|--------|------|------|
| `mainAlt` | 각 상품 | 상품 대표 이미지 (메인 카드 + 상세 갤러리) |
| `thumbs` | 각 상품 | 상세 갤러리 썸네일 (배열) |
| `HERO_SLIDES`의 `alt` | 상단 | 히어로 배너 자동차 이미지 |
| `REVIEWS`의 `alt` | 하단 | 리뷰 포토 |

### 실제 사진으로 바꾸려면

`app.js`의 `phImage()` 함수가 지금은 안내 박스(`<div>`)를 만듭니다.
실제 `<img>` 태그로 바꾸려면 아래처럼 수정하세요.

```js
// app.js — 사진을 실제로 넣을 때
function phImage(src, alt = "") {
  const img = document.createElement("img");
  img.src = src;        // products.js에 이미지 경로를 넣어두면 됨
  img.alt = alt;
  return img;
}
```

그리고 `products.js`에서 안내문 자리에 이미지 경로를 넣으면 됩니다.

```js
// 예시
mainAlt: "images/bubble-bomb.jpg",
thumbs: [
  "images/bubble-bomb-1.jpg",
  "images/bubble-bomb-2.jpg",
  "images/bubble-bomb-3.jpg"
],
```

## 🎨 색상 가이드

모든 색상은 `style.css` 상단의 `:root`에서 CSS 변수로 관리합니다. 한 곳만 바꾸면 전체에 반영됩니다.

| 변수 | 값 | 용도 |
|------|-----|------|
| `--blue` | `#2563eb` | 포인트 (버튼·가격·할인율·CTA) |
| `--navy` | `#0f1f3d` | 히어로 배너·구매버튼·푸터 |
| `--mint` | `#C1EBE9` | 시그니처 민트 |
| `--cyan-bg` | `#5fe3f0` | 인기상품 섹션 배경 |
| `--lilac` | `#cfc7f0` | 연보라 (프로모·사용법 카드) |
| `--green-soft` | `#c3ecc9` | 연녹색 (프로모) |
| `--star` | `#f5b50a` | 별점 노란색 |
| `--red` | `#e11d48` | 상세 할인율 빨강 |

## 🛠️ 상품 추가/수정 방법

`products.js`의 `PRODUCTS` 배열에 객체를 추가하면 메인 카드와 상세페이지가 **자동으로** 생성됩니다.

```js
{
  id: "고유아이디",          // 영문, 중복 금지
  brand: "브랜드명",
  name: "상품명",
  discount: 20,             // 할인율(%)
  price: 25000,             // 판매가(원)
  rating: 4.9,              // 평점
  ratingCount: 1205,        // 리뷰 수
  mainAlt: "대표 이미지 경로/안내문",
  thumbs: ["썸네일1", "썸네일2", "썸네일3"],
  tip: "버블메이트 전문가 팁 내용",
  features: [               // 주요 특징 (보통 2개)
    { title: "특징 제목", body: "특징 설명" }
  ],
  steps: [                  // 사용 방법 (보통 3단계)
    { title: "단계 제목", body: "단계 설명" }
  ]
}
```
